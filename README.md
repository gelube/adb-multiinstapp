# ADB 批量设备安装工具 v3.4

局域网内批量发现 ADB 设备，进行应用安装/卸载/版本管理的 Windows 桌面工具。

## ✨ v3.4 更新

- 修复信号重复连接导致卸载死循环
- 每行设备策略下拉框生效（支持单台设备独立策略）
- 修复补扫阶段闪退
- 安装/卸载计数改为按设备
- 版本信息不再被重置为"待检测"
- 去掉补扫逻辑，加设备ID去重
- IP输入改为范围格式（如 192.168.1.100-200）
- 拖放APK后自动保存配置
- CSV导出apk_name不再为空
- 强制覆盖改为保留数据安装
- 全局crash handler写crash.log

## 🎯 功能特性

### 📱 设备发现
- IP 范围扫描（支持 192.168.1.100-200 格式）
- 自定义 ADB 端口
- 可配置并发扫描数
- 实时显示设备信息（IP、型号、Android 版本）
- 自动保存/加载设备列表

### 📦 应用安装
- 拖放/选择 APK 文件，自动解析版本信息
- 已安装版本检测与对比
- **智能版本策略**（每台设备可独立设置）：
  - 智能对比：自动判断是否需要安装
  - 跳过已安装：已安装即跳过
  - 强制覆盖：保留数据覆盖安装
  - 先卸载再安装：彻底重装
- 可配置并发安装数
- 实时进度显示

### ⚠️ 失败重试
- 自动记录失败设备和原因
- 可选部分或全部重试
- 重试前自动卸载旧版本

### 🗑️ 应用卸载
- 输入包名批量卸载（支持中英文逗号分隔多包名）
- 自动跳过未安装设备
- 实时进度显示

### 📋 日志管理
- 实时日志窗口
- 支持导出日志/CSV

## 📦 安装步骤

1. 从 [Releases](https://github.com/gelube/adb-multiinstapp/releases) 下载最新版 `adb-multiinstapp-dist-v3.4.zip`
2. 解压到任意目录
3. 双击 `启动.bat` 运行

> 无需安装 Python，已打包为独立 exe，内置 adb 工具。

## 📖 使用说明

### 设备发现
1. 输入 IP 范围（如 `100-200` 或 `192.168.1.100-200`）
2. 修改 ADB 端口（默认 5555）
3. 点击"开始扫描"

### 应用安装
1. 拖放或选择 APK 文件
2. 选择版本策略
3. 勾选目标设备（可按行单独设置策略）
4. 点击"开始安装"

### 应用卸载
1. 输入包名（多个包名用逗号分隔）
2. 勾选目标设备
3. 点击"开始卸载"

## 🔧 技术栈

- Python 3.8+ / PyQt5
- subprocess 调用系统 ADB
- concurrent.futures 线程池
- PyInstaller 打包

## ⚠️ 注意事项

- 确保目标设备已开启 USB 调试和无线调试
- 确保电脑和设备在同一局域网
- 首次连接设备需要在设备上授权
- 部分加固/混淆的 APK 可能无法自动识别版本
